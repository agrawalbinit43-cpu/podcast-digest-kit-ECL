# Agent instructions

This repo is the Brave New Law kit: a skill and command-line tool for a chat bot. It has no web app.

1. Read `SKILL.md` first. It is the operating manual.
2. `SPEC.md` explains how search, transcripts and records work, and the traps.
3. `prompts/` holds the breakdown and roundup formats.
4. Run everything through `tools/bnl.py`. Keep `library/` out of git.
5. Never commit secrets, transcripts, records or digests.
